NEXVOLT 3D Product Viewer

A cinematic, interactive 3D product showcase built with Three.js and WebGL. Renders three NEXVOLT energy drink variants in real-time with PBR materials, image-based lighting, a custom GLSL rim-glow shader, and Unreal Engine-style bloom post-processing — entirely in the browser with no server required.

Launch 3D Viewer →

Technology Stack

  • Three.js r128 — 3D rendering engine
  • WebGL — GPU-accelerated rendering
  • GLSL — Custom Fresnel rim shader
  • EffectComposer — Bloom post-processing
  • Web Audio API — Synthesised soundscape
  • Vanilla JS / HTML5 / CSS3

3D Models

  • Slim Can — 250 ml aluminium energy can
  • Sport Bottle — 500 ml ergonomic bottle
  • Crushed Can — Deformed mesh with PBR
  • All models original — created in Blender 4.x
  • Exported as GLTF/GLB format

Rendering Features

  • PBR materials (metalness / roughness)
  • PMREM image-based lighting — no HDR file
  • ACES filmic tone mapping (exposure 0.95)
  • Custom GLSL Fresnel rim-glow overlay
  • Unreal Engine-style bloom (threshold 0.85)
  • Animated drop shadow with float sync

Interaction

  • OrbitControls — orbit, zoom, pan
  • Cinematic camera presets (Hero / Side / Top / Detail)
  • Model rotation buttons (±22.5°)
  • Zoom In / Zoom Out (15% steps)
  • Auto-rotation turntable
  • Wireframe / rim shader / bloom toggles

Accessibility (WCAG 2.1 AA)

  • Full keyboard navigation via Tab
  • aria-pressed on all toggle buttons
  • aria-live region for screen readers
  • Skip-to-main-content link
  • prefers-reduced-motion respected
  • 44 × 44 px minimum touch targets

Performance

  • DPR capped at 2× (avoids 9× pixel cost)
  • GPU memory disposal on every model switch
  • Bloom bypasses EffectComposer when off
  • PMREM disposed immediately after use
  • Debounced resize (100 ms)
  • Page Visibility API pauses render loop
